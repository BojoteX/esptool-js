How to Connect

  1. Click Start below — a device list will appear
  2. Now put your ESP32 in boot mode: hold BOOT, plug in USB, release BOOT
  3. A new device will appear in the list — that's yours!
  4. Select it and click Connect
Already plugged in? Hold BOOT, press RST, release both — a new entry will appear in the list.

A browser popup will appear to select your device
